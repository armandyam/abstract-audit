# abstract-audit

Auditable metrics for research abstracts. This repository contains the full
pipeline behind *LLM Judges Agree With Each Other and Disagree With
Human-Grounded Readability Metrics* (UncertaiNLP 2026, non-archival):
30,595 NeurIPS abstracts from 1987
to 2025, scored by 15 classical readability formulas, 14 other writing metrics,
and six open-weight LLM judges.

Every figure in the paper regenerates from `data/raw/neurips` with one command,
and `verify.py` checks the result against the files that produced the published
figures.

## What is and is not in this repository

**Not here: the abstracts.** NeurIPS abstracts belong to their authors and
publisher, so they are not redistributed. `src/scraping/scrape_neurips.py`
fetches them from `papers.nips.cc`, and every row in this repository is keyed by
a `paper_id` of the form `{year}_{hash}` where the hash is the one in the source
URL, so any row resolves back to its origin:

```
pre-2020   papers.nips.cc/paper/{year}/file/{hash}-Metadata.json
2020+      papers.nips.cc/paper_files/paper/{year}/hash/{hash}-Abstract.html
```

**Here and not regenerable: the judge scores.** `judge_scores/`
holds 1.3 M scored rows from six open-weight models. Reproducing them needs a
GPU and about a day; the harness that produced them is
`src/metrics/llm_scores.py`, with the prompts verbatim.

**Here as expected output: `reference/`.** The per-paper metrics and plot-ready
CSVs that produced the published figures. The pipeline writes its own copies
into `data/`, and `verify.py` compares the two.

## Quickstart

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm

# 1. fetch the corpus (about 30 min, polite rate limiting)
python src/scraping/scrape_neurips.py --start 1987 --end 2025

# 2. everything else
python main.py
```

To skip scraping and work from the shipped metrics instead:

```bash
mkdir -p data/per_paper && cp -R reference/per_paper/. data/per_paper/
python main.py --from aggregate
```

That rebuilds every figure in about 15 seconds without touching the network.

## The figures

`paper/figures.pdf` is the rendered output: seven figures with the captions
they carry in the paper, built from `paper/figs/*.tex` against the data the
pipeline just produced. It is regenerated by the `figures` stage and committed
so it can be read without a TeX installation.

## Layout

```
src/            the pipeline
paper/          figure sources and their generators
judge_scores/   shipped: six models, 1.3 M scored rows, not regenerable
reference/      shipped: expected outputs, and the no-scrape entry path
data/           generated; absent in a fresh clone, rebuilt by main.py
```

Anything tracked in git is either impossible to regenerate (`judge_scores/`)
or is the yardstick the pipeline is checked against (`reference/`). Everything
in `data/` is disposable: delete it and `python main.py` builds it back.

## Stages

```
process      data/raw/neurips -> data/processed/neurips     (schema-validated JSON)
metrics      readability, acronyms, hedging, signposting, narration, hype
metrics_nlp  spaCy: parse depth, NP density, passive rate, TTR, clauses, POS counts
aggregate    per-paper -> per-year mean, std, count; judge scores per model
export       aggregates -> plot-ready CSVs
model_avg    per-model z-scores -> six-model average
analysis     metric-vs-judge Spearman r; the two-panel summary series
figures      the judge-vs-metric heatmap
verify       every artefact against reference/
```

`python main.py --list` shows them; `--stages`, `--from` and `--skip` select.

## The six judges

```
Gemma-3-27B-Instruct    Llama-3.1-8B-Instruct    Mixtral-8x7B-Instruct
Gemma-4-31B-Instruct    Mistral-7B-Instruct      Qwen2.5-32B-Instruct
```

Three 70B models were also scored and are excluded, because none completed:
DeepSeek-R1-Distill-70B produced no parseable scores at all (a reasoning
distill spends the 8-token budget on its preamble), Llama-3.1-70B stopped at
2006, and Llama-3.3-70B finished only two of the three prompts. They are not
shipped.

Decoding is `temperature=0.7`, `do_sample=True`, `max_new_tokens=8`, three runs
per (paper, prompt, model), median reported. Scores are standardised per model
against the 1987-2022 baseline, then averaged.

## Reproducibility

`verify.py` compares 15 per-paper metric files byte-for-byte, 24 plot-ready
CSVs numerically at `atol=0`, and the figure PNG byte-for-byte. It exits
non-zero on any mismatch.

Two things genuinely affect the numbers, so both are pinned in
`requirements.txt`: the `textstat` version, whose formula implementations have
changed between releases, and the spaCy model version, which determines parse
depth, NP density, passive rate and TTR.

If `verify.py` reports a mismatch it also prints the installed versions against
the ones `reference/` was built with. A small numeric difference there is almost
always a version difference, not a broken pipeline.
